# Pawfect Match: screen-based prototype

A separate, interactive proposal. The existing Pawfect Match homepage is preserved.

- Welcome: immersive dog collage and a clear start action.
- Questionnaire: four directly accessible chapters, blank first-run choices, compact fields, and an adjacent recommendation preview.
- Discover: one dog at a time, with adaptive Like/Pass, undo, restart, and a coat filter.
- Your dogs: Recommended, Favorites, and Browse tabs with name/type search.
- Compare: up to three named photo profiles, score rings, fit differences, removable selections, and top-pick confirmation/confetti.
- Theme: light and dark; scores and saved choices use the prototype’s own storage keys.

Static HTML/CSS/JavaScript. It reuses the repository’s matching engine, dog catalog and photographs. To run from the repository: `python3 -m http.server 8092 --directory public`, then open `http://localhost:8092/prototype/`.

Taste direction: Editorial greeting (seed 2097481218), retaining the blue identity and Times New Roman. No new dog facts or sample identities were added. Most profiles remain explicitly marked examples, not adoption listings.
